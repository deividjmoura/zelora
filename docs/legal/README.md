# Documentos legais — Zelora

Os arquivos desta pasta são **minutas de trabalho**, preparadas para orientar produto e desenvolvimento. Não são parecer jurídico, não devem ser publicados como versão definitiva nem aceitos por usuários antes de revisão por advogado com experiência em tecnologia, consumo, contratos e proteção de dados no Brasil.

## Minutas
- [Termos de Uso](terms-of-use.md)
- [Política de Privacidade](privacy-policy.md)
- [Pendências para publicação](publication-checklist.md)

## Antes de publicar
Preencher todos os campos `[PREENCHER]`; confirmar a pessoa jurídica operadora, CNPJ e endereço; definir canais de atendimento e encarregado; validar os fluxos reais de dados e fornecedores; decidir regras de cancelamento, moderação e pagamentos; revisar a compatibilidade com LGPD, Marco Civil da Internet, Código de Defesa do Consumidor e demais normas aplicáveis; obter aprovação jurídica.

Não copiar cláusulas de concorrentes. Os documentos de terceiros foram usados apenas para identificar temas e práticas de mercado; a redação da Zelora deve refletir o funcionamento real do produto.
